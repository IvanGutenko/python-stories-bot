# Python Stories Bot

Telegram-интерфейс для управления публикацией историй через пользовательские сессии Telethon.

**Стек:** Python · aiogram · Telethon · python-socks · asyncio.

## Возможности

- Административный интерфейс и загрузка медиа.
- Управление пользовательскими сессиями, ссылками и упоминаниями в историях.
- Последовательная обработка публикации, настраиваемые задержки и обработка ошибок Telegram.
- Поддержка SOCKS5/HTTP-прокси и повторной авторизации сессий.

## Запуск

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
# Заполнить .env, затем экспортировать значения в окружение:
set -a; source .env; set +a
python bot.py
```

Укажите собственные `API_ID`, `API_HASH`, `BOT_TOKEN`, `ADMIN_ID` и настройки прокси. Пользовательские сессии размещаются локально в `data/sessions/`. Работа с Telegram требует авторизации и учёта ограничений API.

`core/engine.py` содержит конвейер публикации, `handlers/admin.py` — управление. Доступы в публичной копии вынесены в окружение; оригинальная рабочая папка не изменялась. Сессии, списки пользователей, медиа и резервные копии исключены.
